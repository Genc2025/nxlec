## Defect 1 — predictable answer-key schedule (SYSTEMIC, CRITICAL)

Batch importer code explicitly assigns deterministic key schedules instead of an unpredictable shuffle.

- Q0003–Q0100 importer: `keys="BCDEBCDE"+"ABCDE"*18`
- Q0101–Q0200: `keys="ABCDE"*20`
- Q0201–Q0300: `keys="ABCDE"*20`
- Q0301–Q0400: `keys="ABCDE"*20`
- Q0401–Q0500: `keys="ABCDE"*20`

Therefore answer positions are numerically balanced but predictable. This fails strict cueing/bias/fairness at bank level.

Required remediation:
- Reassign answer positions with a deterministic but cryptographically seeded/non-obvious permutation or another non-predictable balanced schedule.
- Preserve exact key concept and distractor text.
- Re-verify correct_answer after permutation.
- Re-run duplicate and technical checks.

Affected: Q0003–Q0500 (498 items).

## Defect 2 — review verdicts/scores are hardcoded by importer (SYSTEMIC, CRITICAL)

The batch importer constructs:
- `verdict="PASS_WITH_NO_CHANGES"`
- all 10 review scores = 10
- every option audit flag = true
- source verification = opened_and_checked true / claim_supported true

These values are created programmatically in the importer before any fresh Step-2 audit. They are therefore not acceptable as independent evidence that the item actually passed those domains.

Affected: Q0003–Q0500 (498 items).

Required remediation:
- Ignore/delete the evidentiary meaning of the old auto-generated PASS fields.
- Perform a fresh item-specific audit.
- Only write PASS after the fresh audit has actually checked the item.

## Defect 3 — generic distractor evidence map (SYSTEMIC, HIGH)

For batch items, the evidence map is generated with the same source IDs S1/S2 for every option. Incorrect options receive a generic inference:
“not the best answer for this vignette; findings are instead explained by [diagnosis].”

This does not independently verify the factual proposition embedded in each distractor, despite `factual_claim_verified=true` being stored.

Affected: Q0003–Q0500 (498 items).

Required remediation:
- For every distractor, verify the factual claim and its item-specific incorrectness.
- Map evidence to the actual mechanism/condition represented by that distractor when needed.
- Do not mark factual_claim_verified=true unless it was actually checked.

## Defect 4 — difficulty metadata is not item-specific (SYSTEMIC, HIGH)

Batch specs contain no explicit difficulty field. Importers default every batch item to `moderate`.

Thus difficulty metadata for Q0003–Q0500 was not independently assessed item by item.

Required remediation:
- Re-rate difficulty during Step-2 audit from actual reasoning burden, not a default.
- Record rationale for easy/moderate/hard classification.

## Defect 5 — format realism gap (BANK-LEVEL, HIGH)

No image/table references were found in batch_specs Q0003–Q0500.
The current USMLE Step 1 description explicitly includes interpretation of graphic/tabular material and identification of gross/microscopic specimens in addition to application of basic-science principles.

This is a bank-coverage/realism gap rather than proof that each text item is individually invalid.

Required remediation:
- Future production must deliberately add image-, table-, graph-, gross pathology-, histology-, and other data-interpretation items using rights-safe assets.
- Existing text items need not all be replaced solely for this reason.
